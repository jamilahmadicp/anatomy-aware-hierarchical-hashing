# Output files

## Stage 1

- `stage1.pt`: best Stage-1 checkpoint.
- `stage1.history.csv`: epoch-wise training/validation losses and accuracy.
- `stage1.calibration.csv`: fitted temperature and calibration statistics.
- `stage1.environment.json`: software/hardware snapshot.
- `stage1_eval/`: final classification metrics, predictions and figures.

## Stage 2

- `stage2_<bits>.pt`: best Stage-2 checkpoint for one code length.
- `stage2_<bits>.history.csv`: loss components, validation classification, validation hash mAP and diversity statistics.
- `stage2_<bits>.environment.json`: environment snapshot.

## Index

- `index_<bits>.npz`: packed and unpacked codes plus route/label metadata.
- `index_<bits>.json`: index construction policy, threshold and storage overhead.
- `hash_audit_<bits>.json`: binary-code quality report.

## Retrieval

Each retrieval directory contains:

- `query_metrics.csv`: one row per query.
- `retrieval_summary.csv`: aggregate mAP, P@K, R@K and nDCG@K.
- `retrieval_examples.json`: top-ranked examples for selected queries.
- `retrieval_examples.png`: qualitative retrieval grid.

## Routing tuning

- `routing_grid.csv`: every validation configuration.
- `selected_routing_hyperparameters.csv`: selected threshold, database top-r, query top-r and alpha.

## Ablations

- `tables/component_ablation.csv`
- `tables/routing_policy_ablation.csv`
- `tables/routing_error_sensitivity.csv`

## MURA

- `classification_128/stage2_metrics.csv`
- `classification_128/stage2_predictions.npz`
- `binary_study/mura_binary_study_metrics.csv`
- ROC, PR, confusion-matrix and t-SNE figures generated by the evaluation scripts.
